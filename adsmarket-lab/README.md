# Ads Marketplace Lab

**A ground-truth simulator of an App Store–style search-ads marketplace, used to grade every experimental, causal, attribution and forecasting method against the known answer.**

In real ads data you never observe the counterfactual, so you can't tell whether your A/B test, your DiD or your attribution model is *right*. Only whether it's *plausible*. This project builds a marketplace where the counterfactual is known exactly: single-slot GSP auctions, cost-per-tap pricing, budget pacing, brand/generic/competitor keywords, and both potential outcomes drawn for every auction. Then it runs the analyses a marketplace data science team actually does and scores each method against the truth.

> All data is simulated. No real Apple data, and no claim about how any real platform works internally.

## The simulator

```
query (country, keyword, hour, user: returning?, engagement)
  └─ eligible advertisers: target keyword ∧ budget left ∧ bid ≥ reserve
       └─ rank by bid × pCTR  →  winner pays max(reserve, 2nd score / own pCTR) per tap
            └─ potential outcomes for the winning app:
                 Y(0) ~ organic install            p0  (high for own-brand searches)
                 Y(1) = organic ∨ (tap ∧ convert)  p1 = p0 + (1−p0)·pCTR·CVR
```

- **120 advertisers × 8 categories, 240 keywords** (one brand keyword per app plus generic terms). Advertisers target their own brand, competitors' brands, generic and off-category terms with different tap and organic-install rates.
- **Budgets** are calibrated so ~45% of advertisers cap out during the day, which is where experiment interference shows up.
- **Confounding is built in on purpose.** Advertisers bid up returning users (who install organically more often), and engaged users have higher pCTR, which wins auctions. Advertisers bid on *attributed* value, because they can't see incrementality.
- **Demand** has country growth, weekly and yearly seasonality, category seasonality (Shopping in Q4, Health in January, Travel in summer), holiday spikes and AR(1) country shocks.
- **Common random numbers.** All randomness for a day is seeded by `(world, day)`, never by policy. Two runs that differ only in policy see the same users and coin flips, so their difference *is* the causal effect. That makes the "global treatment effect" truth exact.

## Run it

```bash
pip install -r requirements.txt
python run_all.py            # ~10 min: every study, figures, report, warehouse, CSVs
python run_all.py --fast     # ~3 min sanity run
python run_all.py --report-only   # re-render from cached outputs/results.pkl
python -m pytest -q tests    # 9 tests: auction invariants, CRN, pacing, estimator recovery
```

Outputs land in `outputs/`: `report.html`, `figures/`, `scorecard.csv`, `reserve_test.csv`, `attribution_by_keyword.csv`, `revenue_plan_90d.csv`, `forecast_backtest.csv`, `kpi_weekly.csv`, `budget_health_weekly.csv` and `warehouse.sqlite`.

## Judgment calls worth discussing

1. **Brand incrementality isn't identified from logs.** Full-sample AIPW still misses (0.129 vs 0.064) because owners almost never lose their own brand auctions, so positivity fails. Instead of tuning the model until it looks right, the observational estimand is restricted to non-brand auctions with common support, and brand goes to an experiment (ghost ads), the design that can actually answer it.
2. **One quasi-experiment is one draw.** In the headline world, DiD reads +12.3% vs a true +8.8%. The event study shows noisy pre-period coefficients from persistent country shocks. Re-running on 8 independent marketplaces shows the estimator is unbiased (−0.7pp) and its CIs cover truth 8/8. The single-world miss is reported, not hidden.
3. **Geo tests leak too.** Shared budgets cross borders: control geos lost 1.0% revenue when the treated geos improved, which pushes DiD up. Same mechanism as finding 1, at a different unit of randomization.
4. **Planning model ≠ lowest-WAPE model.** ETS has the best WAPE but a −1.2% bias. The plan uses the unbiased ensemble (WAPE 3.75% vs 3.69%).

## Known limitations

- **Forecast intervals under-cover:** 71% empirical vs 80% nominal (ensemble). The holiday regime is under-represented in only two years of history. Next step: horizon- and season-specific conformal calibration.
- **Small AIPW bias on the non-brand estimand** of about +0.4pp across 5 worlds, inside the CI each time. Most likely outcome-model calibration on rare binary installs.
- **No ad-vs-organic substitution across apps.** An ad for app A doesn't lower installs of app B (SUTVA at the app level). A real platform would need to measure cannibalization of organic results.
- **Single ad slot, static bids** (no autobidding feedback loops), and daily budgets that grow with trend but not with seasonality.
